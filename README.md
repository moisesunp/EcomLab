# EcomLab Store

EcomLab Store es una tienda de comercio electrónico creada con fines didácticos para el curso de Comercio Electrónico.

## Propósito

El proyecto permitirá observar y practicar progresivamente componentes reales de una tienda electrónica: propuesta de valor, catálogo, productos, carrito, pedidos, clientes, promociones, pagos, logística, posventa y experiencia del usuario.

## Plataforma

La primera implementación se desarrollará como un tema de Shopify y se mantendrá en GitHub para facilitar el control de versiones y el análisis de los cambios realizados durante el curso.

## Primera etapa

Esta versión inicial contiene únicamente:

- estructura mínima del tema Shopify;
- portada de EcomLab Store;
- sección principal editable;
- estilos base.

Las funcionalidades se incorporarán progresivamente para que cada etapa pueda utilizarse con fines didácticos.

## Aviso

Este proyecto es demostrativo. EcomLab Store no representa, por sí misma, una tienda comercial operativa ni procesa ventas reales mientras no se configuren expresamente productos, pagos y demás servicios en Shopify.
